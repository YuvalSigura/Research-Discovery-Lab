# Typed registries (v2)

This layer complements rather than rewrites the original `research/cases/` source catalogue.

- Sources are publications; cases are investigations; findings are outcomes; mechanisms are generalizations.
- Systems and environments are separate: one system can have many versions and deployments.
- Unknown fields remain unknown; do not infer product/version from article titles.
- Context snapshots require time-scoped known observations and hindsight review.
- Relations have explicit typed predicates and provenance.
- The legacy crosswalk preserves all 50 identifiers; their new case records are **unclassified placeholders**, not validated investigation decompositions.
- Add new records to the appropriate `registry/<type>/index.json`; validate before commit.
